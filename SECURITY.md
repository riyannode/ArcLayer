# Security Policy

## Reporting a Vulnerability

If you find a security issue, **do not open a public issue**.

Send details directly to the maintainers:

- Open a **private security advisory** via GitHub:  
  `https://github.com/riyannode/ArcLayer/security/advisories/new`

Or reach out via the repository's contact method.

## What to include

- Description of the vulnerability.
- Steps to reproduce (if applicable).
- Potential impact.

## Response

We'll acknowledge receipt within 48 hours and work on a fix before public disclosure.
