# ArcLayer Indexing Layer

The contract is the source of truth. The indexer is a cache builder for fast dashboard and grant-review views.

## Architecture Overview

```txt
                    ┌─────────────────────────────────┐
                    │          Arc Testnet RPC         │
                    │  (ERC-8183 + ERC-8004 contracts) │
                    └──────────┬──────────┬────────────┘
                               │          │
                    ┌──────────▼──┐  ┌────▼────────────┐
                    │  PM2/SQLite │  │  Goldsky Pipeline│
                    │  (custom)   │  │  (production)    │
                    └──────┬──────┘  └────┬────────────┘
                           │              │
                           │         ┌────▼────────────┐
                           │         │  Postgres Raw    │
                           │         │  Tables          │
                           │         └────┬────────────┘
                           │              │
                    ┌──────▼──────────────▼────────────┐
                    │       API Route (provider gate)   │
                    │  INDEXER_PROVIDER=custom|goldsky  │
                    └──────────────┬───────────────────┘
                                   │
                    ┌──────────────▼───────────────────┐
                    │   ArcLayer Gate (scope filter)    │
                    │  INDEXER_SCOPE=arclayer|arcnetwork│
                    └──────────────┬───────────────────┘
                                   │
                    ┌──────────────▼───────────────────┐
                    │         Console UI / API          │
                    └──────────────────────────────────┘
```

## Indexer Providers

### Custom (PM2/SQLite) — Dev & Fallback

The self-hosted indexer polls Arc Testnet RPC every 15-30s, decodes events into SQLite, and serves projections via HTTP on port 3535.

**Use for:** local development, CI, fallback when Goldsky is down.

```bash
# Start the PM2 indexer
cd indexer && pnpm dev
# or via PM2
pm2 start indexer/dist/server.js --name arclayer-indexer
```

The PM2 indexer reads these env vars:
- `ARC_RPC_URL` — Arc Testnet RPC endpoint
- `FROM_BLOCK` — starting block for event sync
- `POLL_INTERVAL_MS` — sync interval (default 30000)
- `ARC_REFERENCE_WALLET_FILTER` — comma-separated wallet allowlist
- `ARC_REFERENCE_AGENT_ID_FILTER` — comma-separated agent ID allowlist
- `ARC_REFERENCE_METADATA_PREFIX_FILTER` — metadata URI prefixes (default: `arclayer://,https://arclayers.xyz`)

### Goldsky — Production Ingestion

Goldsky handles event ingestion, decoding, and Postgres writes. The ArcLayer reader layer (`goldsky-indexer.ts`) queries Postgres raw tables and applies gate logic.

**Use for:** production, high-throughput indexing, historical backfill.

```bash
# 1. Create the pipeline (one-time)
goldsky pipeline create arclayer-arc-events

# 2. Export the pipeline definition (replace the draft)
goldsky pipeline get-definition arclayer-arc-events > goldsky/arclayer-events.yaml

# 3. Validate
goldsky turbo validate goldsky/arclayer-events.yaml

# 4. Apply the pipeline
goldsky pipeline apply goldsky/arclayer-events.yaml --status ACTIVE

# 5. Monitor the pipeline
goldsky pipeline monitor arclayer-arc-events
```

**⚠️ Status:** The file at `goldsky/arclayer-events.draft.yaml` is a **pseudo config / design doc**. It documents the intended contract → table mapping but uses a simplified format that is NOT `goldsky pipeline apply` compatible. The actual YAML must be generated by `goldsky pipeline get-definition` and may differ in schema (e.g. `apiVersion: 3`, `secret_name` instead of `secret`, object-keyed sources/sinks, auto-created columns).

Goldsky reader env vars:
- `GOLDSKY_POSTGRES_URL` — Postgres connection string for the reader layer
- `GOLDSKY_POSTGRES_SCHEMA` — Postgres schema (default: `public`)

Secret for Goldsky pipeline:
- `GOLDSKY_ARCLAYER_POSTGRES` — Postgres connection string configured in Goldsky project settings

## Raw Tables

The Goldsky pipeline writes decoded events to these Postgres tables:

| Table | Source Contract | Events |
|-------|---------------|--------|
| `goldsky_erc8183_events_raw` | AgenticCommerce `0x0747...4583` | JobCreated, BudgetSet, JobFunded, JobSubmitted, JobCompleted, JobRejected, JobExpired |
| `goldsky_erc8004_identity_events_raw` | IdentityRegistry `0x8004...BD9e` | Transfer (from=0x0 signals registration) |
| `goldsky_erc8004_reputation_events_raw` | ReputationRegistry `0x8004...8713` | NewFeedback |

These are raw event tables. The reader layer applies projection + gate logic before serving to the API.

## Indexer Scope (ArcLayer Gate)

The `INDEXER_SCOPE` env var controls whether the API exposes only ArcLayer-registered activity or all Arc reference activity.

### `INDEXER_SCOPE=arclayer` (default)

Only agents/jobs registered through or linked to ArcLayer are visible:

**Jobs** visible if:
- `client` matches an allowed wallet, OR
- `provider` matches an allowed wallet, OR
- `evaluator` matches an allowed wallet

**Agents** visible if:
- `source` is `imported_arclayer_registry`, OR
- `controller` matches an allowed wallet, OR
- `controller` appears in a retained ArcLayer job, OR
- `agentId` matches an allowed agent ID, OR
- `metadataURI` starts with `arclayer://`, OR
- `metadataURI` starts with `https://arclayers.xyz`

Allowed wallets/agent IDs come from:
1. `ARC_REFERENCE_WALLET_FILTER` env var
2. `ARC_REFERENCE_AGENT_ID_FILTER` env var
3. Supabase `agent_manifests` table (agent_id, controller, signer)
4. Supabase `a2a_jobs` table (provider, evaluator, claimed_by)

**⚠️ Phase 2 requirement:** When `INDEXER_SCOPE=arclayer` with zero allowed wallets and zero allowed agent IDs, the health endpoint must return unhealthy. This behavior will be implemented in the Goldsky reader layer (Phase 2).

### `INDEXER_SCOPE=arcnetwork`

Bypasses the ArcLayer gate. All indexed Arc reference activity is exposed — every ERC-8004 identity registration and every ERC-8183 job on the contracts, regardless of whether it came through ArcLayer.

**Use for:** ecosystem-wide analytics, grant review dashboards, full Arc explorer views.

## Env Var Reference

| Variable | Default | Description |
|----------|---------|-------------|
| `INDEXER_PROVIDER` | `custom` | `custom` (PM2/SQLite) or `goldsky` (Postgres) |
| `INDEXER_SCOPE` | `arclayer` | `arclayer` (gated) or `arcnetwork` (full Arc) |
| `INDEXER_FALLBACK_URL` | _(empty)_ | Fallback URL when Goldsky reader fails (e.g. `http://localhost:3535`) |
| `GOLDSKY_POSTGRES_URL` | _(empty)_ | Postgres connection string for Goldsky reader |
| `GOLDSKY_POSTGRES_SCHEMA` | `public` | Postgres schema for raw tables |
| `ARC_REFERENCE_WALLET_FILTER` | _(empty)_ | Comma-separated wallet allowlist |
| `ARC_REFERENCE_AGENT_ID_FILTER` | _(empty)_ | Comma-separated agent ID allowlist |
| `ARC_REFERENCE_METADATA_PREFIX_FILTER` | `arclayer://,https://arclayers.xyz` | Metadata URI prefixes for agent filtering |

## Runtime Rule

If cached data disagrees with an onchain read, the onchain read wins.
