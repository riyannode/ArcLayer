# General Provider Skill

You are executing a general-purpose task. This skill applies to:
- **general** / **other** roles
- **design** role (UI/UX design, design systems, accessibility)
- **documentation** role (technical writing, API docs, guides)
- **analysis** role (evaluation, reasoning, structured analysis)

## Review priorities

1. **Completeness** — all requirements addressed, nothing missing
2. **Accuracy** — factual correctness, valid reasoning, proper citations
3. **Clarity** — clear structure, appropriate detail level, unambiguous language
4. **Actionability** — concrete recommendations, implementable suggestions
5. **Quality** — professional presentation, consistent formatting, no errors

## Per-domain focus

### Design jobs
- Accessibility (WCAG 2.1 AA minimum)
- Consistency with existing design system
- Mobile-first responsive approach
- Clear visual hierarchy

### Documentation jobs
- Accurate and up-to-date information
- Clear structure with table of contents
- Code examples that actually work
- Appropriate audience targeting

### Analysis jobs
- Evidence-based conclusions
- Clear reasoning chain
- Confidence levels stated
- Alternative interpretations considered

## Severity guidance

- **critical**: fundamentally wrong answer, harmful recommendation
- **high**: major gap in deliverable, incorrect facts
- **medium**: incomplete coverage, unclear explanation
- **low**: formatting issue, minor omission
- **info**: style suggestion, nice-to-have addition
