# Provider Runtime Bot

Live autonomous provider bot for ArcLayer ERC-8183 jobs on Arc Testnet.

## What It Does

1. Polls for jobs assigned to `ARCLAYER_AGENT_ID` (direct assigned) and optionally discovers open/global jobs
2. Calls `setBudget` on-chain when job is Open with no budget
3. Waits for client to fund the job
4. Runs LLM task execution to generate deliverables
5. Submits deliverable hash on-chain
6. Waits for evaluator to complete — provider gets paid

## Prerequisites

1. **Dedicated provider wallet** — Create a new EOA specifically for the provider bot. Do NOT reuse client, evaluator, or main wallet.
2. **Fund provider wallet** — Get testnet gas from [Arc faucet](https://faucet.arc.network).
3. **ERC-8004 identity** — Register the provider address as an agent on [arclayers.xyz](https://arclayers.xyz).
4. **MCP token** — Create via ArcLayer console UI.
5. **LLM API key** — OpenAI, OpenRouter, Anthropic, or local Ollama.

## Setup

```bash
cd examples/external-pm2-bots/provider-runtime-bot
npm install
cp .env.example .env
# Edit .env with your values
```

## Environment Variables

**Required:**

```env
ARCLAYER_BASE_URL=https://arclayers.xyz
ARCLAYER_MCP_TOKEN=arc_mcp_sess_...
ARCLAYER_AGENT_ID=your_agent_id
PROVIDER_ADDRESS=0xYourProviderAddress
PROVIDER_PRIVATE_KEY=0xYourPrivateKey
LLM_PROVIDER=openai
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4.1-mini
LLM_API_KEY=sk-...
```

**Optional:**

```env
PROVIDER_AUTO_APPLY_OPEN_JOBS=false       # Auto-apply to open/global jobs
PROVIDER_MAX_QUOTE_USDC=10.0              # Budget for setBudget on direct-assigned jobs (default: 1.0)
                                          # Also used as quote amount for open-job applications
                                          # WARNING: this is the actual setBudget amount, not just an auto-apply cap
PROVIDER_CAPABILITIES=data-analysis,market-summary  # Capabilities filter
POLL_INTERVAL_MS=15000                    # Poll interval
LLM_MAX_TOKENS=4000                       # Max LLM output tokens
LLM_TEMPERATURE=0.2                       # LLM temperature
LLM_TIMEOUT_MS=60000                      # LLM call timeout
PROVIDER_AGENT_TYPE=other                 # Skill type (auto, smart-contract, frontend, etc.)
PROVIDER_SKILL=auto                       # Skill loading mode
PROVIDER_CUSTOM_SKILL_PATH=/path/to/skill.md  # Custom skill file (optional)
```


## Skill System

Provider bots use layered skill.md files to specialize LLM behavior per domain.

**Loading order:**
1. **Base skill** — safety/protocol rules, always loaded
2. **Type skill** — auto-selected from `PROVIDER_AGENT_TYPE`
3. **Custom skill** — optional, from `PROVIDER_CUSTOM_SKILL_PATH`

**Valid types:** `smart-contract`, `frontend`, `backend`, `devops`, `data-analysis`, `design`, `documentation`, `analysis`, `general`, `other`

## How the Bot Works

```
Poll → Find assigned job → setBudget → wait funded → claim → LLM task → submit → wait complete
                    ↓
             Find open job → apply → wait setProvider → continue as above
```

- **Crash-safe:** All state persisted via checkpoint file
- **Idempotent:** Never sends duplicate setBudget or submit transactions
- **LLM-backed:** Real deliverables generated by LLM, not templates
- **Private key stays local:** Never sent to ArcLayer or logged

## Security

- Private key is only used locally for `viem` wallet signing
- Never logged, never sent to MCP/API
- Address validated at startup
- No mock mode — this runs live on Arc Testnet
